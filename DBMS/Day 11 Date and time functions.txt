SQL Date and Time Functions
curdate()-->It returns the current date
curtime()-->It returns the current time
now()-->returns the current date and time
time()--> extract time part
date() -->extract date part
year() -->extract year
month() -->extract month
day() -->extract day of month
week() -->extract week number
dayofweek() -->day of the week
date_add -->add time to date
date_sub
datediff

SET Operators:
Union(): Combines results from two queries and removes duplicate rows, Columns must have the same 
number and type

UNION ALL: Combines results from two queries and includes all rows, including duplicates.
columns must have the same number and type

INTERSECT: returns rows that are common to both queries. columns must have the same number and type.
Note:MySQL doesn't support intersect directly

MINUS:Returns rows from the first query that are not present in the second query. columns must have the same
number and type.Note: MySQL doesn't support minus directly

JOINS intro:
INNER JOIN: Matched records from both tables
LEFT JOIN: Matched records + left table records
RIGHT JOIN: Matched records + right table records
FULL JOIN: Inner join +right join + left join
CROSS JOIN: It performs cartesian product
