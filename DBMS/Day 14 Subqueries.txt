What is a subquery?
A subquery is a query inside another query 
It is written inside parenthesis() and its result is used by the outer query

It is also called as
inner query
nested query
inner select

General syntax:
----------------
select column-list
from table 
where column operator(select column from table where condition);

Purpose of subquery
-------------------
To breakdown complex problems into smaller queries
To use the result of one query as input to another
To avoid multiple steps (write in a single query instead of temp tables).

Types of subqueries:
--------------------
1.Single row sub query
2.Multirow sub query
3.nested subquery
4.corelated subquery
5.exists/not exists subquery.

1.single row subquery:
----------------------
single row subqueries returns exactly one row and one column They use comparision operators like
=,>,>=,<,<=,!=

Characteristics
---------------
returns only one value
can use single-value comparision operator
if subquery returns no rows or multiple rows,it causes an error

syntax
------
select columns
from table
where column Operator(select column from table where condition);

2.Multi-row subquery:
---------------------
Multi-rows Subqueries(IN)
A multi row subquery returns more than one row.Then in operator is used when you want to compare
a value with multiple values returned by the subquery
characterstics
returns multiple rows
uses the IN operator
checks whether a value exists in list returned by the subquery
equivalent to multiple or conditions
most commonly used for matching values

syntax:
select columns from table
where column IN(select column from table where condition);

3.Multi row subqueries(ANY/SOME)
Multi rows subqueries returns mutiple rows when using any or some,the condition is true if it matches
at least one value returned by the subquery

Characterstics
returns multiple values
ANY and SOME are interchangeable
condition is true if any of the satisfy the condition
often used with IN,>ANY,<ANY,=ANY..etc
Syntax:
select columns from table
where column Operator ANY/SOME(select column from table where condition);

4.Multi-row Subquery (ALL)
The ALL operator means the condition must be true for all values return by the subquery

Characteristicts
Condition must be true for all values in the subquery result.
often used with >ALL,<ALL,>=ALL,<=ALL
>ALL means greater than the maximum values
<ALL means less than the minimum values.

SYntax:
select columns from table
where column operator ALL(select column from table where condition);

5.Nested subquery:
nested subqueries are subqueries with subqueries They can be multiple level deep and are executed 
from the innermost to the outermost

Charactersticts
Multiple levels of nesting
Inner queries execute first
Can combine different types of subqueries
Useful for complex conditions

Syntax:
SELECT column_list
FROM table 
WHERE column =(SELECT column
               FROM table
               WHERE column =(SELECT column
                               FROM table
                               WHERE condition));
6.Corelated subquery
Corelated subqueries are subqueries that reference column from the outer query.Unlike regular subqueries
that execute once,corelated subqueries executes once for each row processed by the outer query

Charactersticts
references column from the outer query
executes multiple times(once per outer row).
Cannot be executed independently
often used with EXISTS,NOT EXISTS
Generally slower than non-corelated subqueries.

Syntax:
SELECT columns
FROM table1 outer_alias
WHERE condition(SELECT column
               FROM table2 inner_alias
               WHERE inner_alias.column=outer_alias.column);                                                              

7.Exists/not exists subquery
EXISTS is used to test whether a subquery returns any rows.It returns true if the
subquery returns at least one row.False otherwise NOT EXISTS returns true if the subquery returns no rows.

Charactersticts
returns TRUE/FALSE(Boolean result)
more efficient than in large datasets
often used with co related subqueries
stops execution as soon as first match is found.
Select clause is exists doesnt matter (often use SELECT 1)

SYNTAX
------
select columns
from table1
where exists(select 1 from table2 where condition);

select columns
from table1
where NOT exists(select 1 from table2 where condition);
